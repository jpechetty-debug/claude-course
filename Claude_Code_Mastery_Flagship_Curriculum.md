# Claude Code Mastery: Zero to Production AI Engineer
## Enterprise Curriculum Architecture & Learning System

> **A Comprehensive Hands-On Engineering Program for Claude Code & Agent Systems**  
> **Duration:** 60 Days · 8 Weeks · 120 Total Learning & Lab Hours  
> **Audience:** Developers, AI Engineers, Startup Founders, and Technical Leaders

---

## Executive Summary & System Overview

This curriculum provides a structured, hands-on path for mastering Claude Code, custom Model Context Protocol (MCP) servers, deterministic hooks, subagents, and the Claude Agent SDK. The curriculum emphasizes developer safety, verified planning in Plan Mode, deterministic security guardrails, and production CI/CD automation.

The curriculum is structured across the following core documents in this repository:

1. [01_Curriculum_Audit_and_Gap_Analysis.md](./01_Curriculum_Audit_and_Gap_Analysis.md) — Structural audit of the baseline companion and 20 enterprise gap resolutions with pedagogical rationale.
2. [02_Course_Blueprint_and_Syllabus.md](./02_Course_Blueprint_and_Syllabus.md) — 60-day day-by-day syllabus, program branding options, core learning goals, and 4 skill tiers.
3. [03_Hands_On_Labs_Catalog_50.md](./03_Hands_On_Labs_Catalog_50.md) — 50 standalone hands-on labs with complete commands, inputs, expected outputs, and pass criteria.
4. [04_Capstone_Projects_Catalog_30.md](./04_Capstone_Projects_Catalog_30.md) — 30 industry capstones (5 Beginner, 10 Intermediate, 10 Advanced, 5 Expert) with system architectures and rubrics.
5. [05_LMS_Production_and_Certification_Framework.md](./05_LMS_Production_and_Certification_Framework.md) — 7-part lesson production blueprint, fully authored flagship lesson packages, and career roadmaps.
6. [Interactive Web Dashboard (`zip_extracted/`)](./zip_extracted/) — Full React/Vite web application dashboard rendering all 9 phases, searchable 50 Labs catalog, filtered 30 Capstones, and modular syllabus.
